# OpenGuardian 知识库建设计划（组合技版）

> 版本：v1.0（2026-08-02）· 状态：待 CEO 确认
> 核心理念：**知识库数据源迁移到 Obsidian，让团队用组合技协作维护**

## 1. 为什么用组合技

| 组件 | 在知识库建设中的角色 |
|---|---|
| **Obsidian** | 知识条目可视化、`[[wikilink]]` 关联图谱、团队编辑界面（纯 Markdown，人人可改） |
| **Claudian** | Obsidian 内 AI 辅助：对话生成新条目、批量翻译安全文档为术语条目、校对润色 |
| **Hermes** | 自动化中枢：`build.py` 扫描 vault → 生成 Python 模块 → 跑测试 → git 提交；cron 定时同步 |

**现状痛点**：147 条知识全在 Python 文件里，只有开发者能改，无法团队协作、无法可视化。

**目标**：知识 = 数据（Obsidian md）≠ 代码（Python 生成物）。数据与逻辑分离。

    │   ├── 📄 勒索软件.md

## 4. 条目格式规范（frontmatter + 正文）

```markdown
---
type: glossary                  # glossary | malware | case
keywords: [木马, trojan, trojan horse]   # 匹配关键字（含变体）
level: critical                 # 仅 malware：low/medium/high/critical
category: 恶意软件               # 分类标签
tags: [恶意软件, 入门]
---

# 木马

## 大白话解释
伪装成正常软件偷偷安装、在后台干坏事的程序。

## 类比
快递箱里夹带的窃听器——外表是普通包裹，里面另有玄机。

## 防护建议
只从官方渠道下载软件，安装时看清勾选项。
```

**规范约束**（build.py 校验，不合规拒绝生成）：
- frontmatter 必须有 `type` + `keywords`
- 正文必须含「大白话解释」小节
- 文件名 = 主术语名

## 5. 同步机制（Hermes 自动化层）

```
[Obsidian vault]  --build.py 扫描-->  [Python 模块]  --测试-->  [git 提交]
       ↑                                                              │
       └──────────── cron 每日 20:00 自动执行 <───────────────────────┘
```

- `backend/scripts/build_kb.py`：扫描 vault → 校验条目 → 生成 `app/kb/generated_*.py`
- 生成后自动跑 `unittest`，通过才提交（**测试守护**）
- cron 定时任务：每日自动同步（组合技自动化闭环）
- 保留手工触发：`python scripts/build_kb.py`

## 6. 实施步骤（两周）

### 第 1 周：基础设施（Hermes 主导）
1. vault 建 `OpenGuardian-KB/` 目录骨架 + `INDEX.md`
2. 写 `build_kb.py`：解析 md → 校验 → 生成 Python 模块
3. **迁移现有 147 条**：Python → md（脚本自动转换，保留全部内容）
4. 跑通同步闭环：build → 测试 → 提交
5. **验收**：vault 里能看图谱，服务仍 25/25 测试通过

## 7. 质量保障

1. **build 校验**：缺 frontmatter/正文小节 → 拒绝生成并报告文件名
2. **测试守护**：知识变更必须过 25+ 项测试（术语查询、特征命中、案例返回）
3. **双人审校**：AI 生成的条目必须至少 1 名团队成员在 Obsidian 里审校后合入
4. **版本管理**：vault 知识目录纳入 git，每次扩充可追溯

## 8. 组合技闭环演示脚本

1. **Claudian 生成**：Obsidian 里输入"给'杀猪盘'写一条术语条目，按规范格式" → md 文件生成
2. **Hermes 同步**：跑 `build_kb.py` → 生成模块 → 测试 → 提交
3. **产品生效**：重启服务 → 问"什么是杀猪盘" → 术语库命中 → 通俗解答
4. **图谱呈现**：Obsidian graph view 展示术语间 `[[关联]]`

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| md 格式不合规导致构建失败 | build 输出详细错误报告，标注文件名+原因 |
| AI 生成条目有事实错误 | 双人审校制度 + 只允许合入已审校条目 |
| vault 路径变动 | 路径配置进 `.env`（`OBSIDIAN_VAULT_PATH`） |
| 知识库膨胀失控 | INDEX 维护 + 分类目录约束 + 定期清理会议 |
