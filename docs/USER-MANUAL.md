# OpenGuardian 用户手册

**版本**：v0.7.0  
**适用平台**：Windows 10 / 11（64 位）

---

## 一、安装指南

### 1.1 系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 1809+ / Windows 11 |
| 内存 | ≥ 4GB（推荐 8GB） |
| 磁盘空间 | ≥ 500MB |
| 网络 | 首次使用需联网（威胁情报更新/LLM 服务） |

### 1.2 安装步骤

1. 双击 `OpenGuardian-0.7.0-Setup.exe`
2. 安装向导选择语言（简体中文/English）
3. 选择安装目录（默认 `C:\Program Files\OpenGuardian`）
4. 勾选"创建桌面快捷方式"
5. 点击"安装"完成

### 1.3 首次启动

1. 双击桌面 `OpenGuardian` 图标
2. 首次启动会打开**配置向导**，选择 AI 提供商
3. 填入 API Key（DeepSeek 等 25 家可选）
4. 点击"保存"，系统自动验证连接

> 💡 **提示**：没有 API Key 也可以使用检测功能（检测不依赖 AI），只是对话功能受限。

### 1.4 卸载

- 控制面板 → 程序 → 卸载 OpenGuardian
- 卸载将**彻底清除**所有配置、数据库和日志（不残留）

## 三、核心功能

### 3.1 全量安全检测

**方式一**：在助手对话框输入 `帮我检测一下电脑`  
**方式二**：点击欢迎卡"帮我检测一下电脑"

检测内容（约 12 秒并行完成）：

| 检测项 | 说明 |
|---|---|
| 恶意进程 | 特征库 + 病毒哈希双重匹配 |
| 恶意网络连接 | 威胁情报 IP/域名比对 |
| 系统漏洞 | 补丁/SMBv1/防火墙/Guest/UAC/共享等 |
| Defender 状态 | 防病毒引擎健康 |
| 系统更新 | 补丁数量审计 |
| 风险服务 | 高危险服务排查 |
| 账户安全 | 密码策略/自动登录/Guest |

**结果展示**：AI 用白话解释每项风险 + 具体修复步骤。

### 3.2 智能对话

OpenGuardian 自动识别你的意图：

| 你说 | 它做什么 |
|---|---|
| "帮我检测一下电脑" | 全量安全扫描 |
| "检查密码 xxxxxx" | zxcvbn 密码强度评估 |
| "讲讲勒索病毒" | 从案例库调取安全课堂 |
| "什么是钓鱼邮件？" | 案例/LLM 科普 |
| "结束进程 1234" | 一键处置可疑进程 |
| 其他安全问题 | LLM 深度解答 |

### 3.3 密码强度检测

输入任意密码，系统给出：
- **评分**：0-4 分（zxcvbn 算法，与 Dropbox 同源）
- **破解力估算**：多少次尝试可破解
- **改进建议**：具体可操作建议

### 3.4 安全知识库

- **安全课堂**：29 个真实场景案例（刷单诈骗/钓鱼邮件/勒索病毒…）
- **术语解释**：114 个专业术语自动翻译成大白话
- **RAG 检索**：未命中案例的话题，自动检索知识库后 AI 解答

## 五、配置管理

### 5.1 修改 AI 提供商

打开 `http://127.0.0.1:8300/config`（或设置页）：

1. 选择提供商（25 家可选）
2. 输入 API Key
3. 选择模型（或手动输入）
4. 点击保存并测试

### 5.2 API Key 安全

- Key 首次使用后自动**加密存储**（机器绑定）
- 更换电脑/重装系统后需重新配置
- 支持从 `.env` 文件读取（开发模式）

## 六、常见问题（FAQ）

### Q1: 检测需要联网吗？
检测本身**不需要**联网（本地引擎+本地情报库）。威胁情报更新和 AI 对话需要联网。

### Q2: AI 对话提示"无法连接"？
1. 检查 `设置页` 中 API Key 是否正确
2. 检查网络连接
3. 尝试更换提供商（25 家可选）

### Q3: 检测结果看不懂？
点击风险条目展开"修复建议"，或直接问 AI："这个风险怎么处理？"

### Q4: 会不会误杀我的软件？
- 检测只**报告**不自动处置（默认安全模式）
- 一键处置前会弹窗确认
- 支持将信任软件加入白名单

### Q5: 数据存在哪里？
- 数据库：`%LOCALAPPDATA%\OpenGuardian\openguardian.db`
- 配置：`%LOCALAPPDATA%\OpenGuardian\config.json`
- 卸载时全部清除

## 七、安全承诺

- **本地优先**：检测数据不出本机
- **零模拟数据**：所有检测结果来自真实系统/权威情报源
- **最小权限**：检测只读系统状态，处置需用户确认
- **透明可溯**：每项风险附带检测依据与修复步骤
